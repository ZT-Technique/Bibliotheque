Architecture Logicielle

Routes & Entrées

Le point d'entrée admin est sécurisé et masqué par l'URI /site-admin0018.

  • • Routes Publiques : Gérées par PublicController
  • • Routes Authentifiées : Sécurisées via Middleware auth + is_admin

Moteurs de Rendu

Utilisation massive de Blade Templates segmentés par composants pour une réutilisabilité maximale.

Contrôleurs Clés

ArticleController : Gère les uploads PDF, couvertures, duplication et visibilité.
StatsController : Analyse complexe des visites et téléchargements.
ContactController : Messagerie asynchrone pour le support et les feedbacks.

Schéma Base de Données

Table: articles

Champ Type Détail
id BIGINT UNSIGNED Primary Key
title VARCHAR(500) Titre complet de la publication
authors VARCHAR(500) Liste des auteurs
theme_id BIGINT UNSIGNED Foreign Key (themes.id)
abstract TEXT Résumé / Abstract
pdf_path VARCHAR(255) Chemin du fichier stocké
downloads_count INT Default: 0
is_visible BOOLEAN Default: true

Table: themes

Champ Type Détail
id BIGINT UNSIGNED Primary Key
name VARCHAR(255) Nom de la thématique
description TEXT Nullable

Table: users

Champ Type Détail
is_admin BOOLEAN Droit d'accès d'administration
profile_photo VARCHAR(255) Image de profil admin

Modèles & Relations

Model: Article

RELATION : belongsTo(Theme::class)
Fillables :

title, authors, year, theme_id, abstract, keywords, pdf_path, cover_image, downloads_count, is_visible

Model: Theme

RELATION : hasMany(Article::class)
Fillables :

name, description
